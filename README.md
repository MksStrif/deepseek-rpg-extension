# 🎲 DeepSeek RPG Extension

*Демонстрация работы боковой панели в реальном времени*

Расширение для браузера (Chrome / Яндекс.Браузер), которое превращает чат с ИИ в полноценную текстовую RPG.

## 🌟 Что это?
Это графический движок, который накладывается поверх интерфейса DeepSeek. Нейросеть управляет сюжетом и отправляет скрытые команды в системных блоках `[SYS] ... [/SYS]`, а расширение парсит их и меняет интерфейс в реальном времени.

## 🚀 Возможности
- 🎒 **Инвентарь и Вкладки:** Предметы со свойствами (прочность, патроны, золото).
- 📊 **Счетчики:** Здоровье, Мана, Выносливость, Рассудок и любые другие.
- ⏱️ **Таймеры:** Отложенные события (взрывы, письма, облавы).
- 📅 **Фэнтезийные календари:** Поддержка любых дат (например, "17-е Вечерней Звезды").
- 📈 **Уровни и Опыт:** Линейная или экспоненциальная прогрессия.
- ⚔️ **Боевая система:** HP врагов, статусы (кровотечение, замедление).
- 🎲 **Броски кубиков:** Встроенный HUD с d20, d6 и 2d6.

## 🛠 Установка
1. Скачайте ZIP-архив в разделе **Releases**.
2. Распакуйте его в любую папку.
3. Откройте `chrome://extensions/` (или `browser://extensions/` в Яндексе).
4. Включите **«Режим разработчика»**.
5. Нажмите **«Загрузить распакованное расширение»** и выберите папку с расширением.

## 🎮 Как начать играть?
1. Откройте [chat.deepseek.com](https://chat.deepseek.com).
2. Откройте боковую панель расширения.
3. Нажмите кнопку **«📋 Промпт»**, чтобы скопировать системный промпт.
4. Отправьте промпт в чат DeepSeek. Игра началась!
